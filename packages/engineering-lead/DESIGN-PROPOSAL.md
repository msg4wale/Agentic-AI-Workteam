# Engineering Lead Agent — Design Proposal

## Role

Convert validated `PRD.md` and `TDD.md` into a complete, dependency-aware, issue-ready `Engineering-Plan.md`.

## Skills

1. `engineering-readiness-analysis`
2. `technical-task-decomposition`
3. `qa-verification-planning`
4. `dependency-sequencing-analysis`
5. `engineering-issue-specification`
6. `engineering-plan-validation`

## Core Outputs

The single `Engineering-Plan.md` contains:

- workstreams;
- implementation tasks;
- QA tasks;
- coverage matrix;
- dependency matrix;
- implementation waves;
- parallelization opportunities;
- structural critical path;
- integration checkpoints;
- engineering risks/blockers;
- issue-ready specifications.

## Boundary

The Engineering Lead decides how to package and sequence implementation work.

The Engineering Lead does not make new product or architecture decisions.

## Handoff Contract

Inputs:
- `PRD.md`
- `TDD.md`

Output:
- `Engineering-Plan.md`

Next owners:
- Software Engineer(s)
- QA Engineer(s)
- Platform/DevOps Engineer(s)
- Other implementation specialists as required
