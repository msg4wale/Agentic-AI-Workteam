# Product Manager Agent — Design Proposal

## Role

Convert a validated `idea.md` into an architecture-ready `PRD.md`.

## New Skills

1. `product-framing-synthesis`
2. `epic-user-story-design`
3. `requirements-acceptance-criteria`
4. `prioritization-release-planning`
5. `product-quality-metrics`
6. `prd-validation`

## Shared Skill Reused

- `idea-validation` from the Idea Discovery package

## Boundary

The Product Manager may elaborate, structure, trace, prioritize, and specify acceptance conditions.

It must not invent business policy, perform discovery by assumption, design architecture, or create engineering tasks.

## Handoff Contract

Input: `idea.md`

Output: `PRD.md`

Next owner: Solution Architect
